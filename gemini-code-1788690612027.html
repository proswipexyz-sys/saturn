SATURN - SETUP

Saturn Spooferのセットアップ手順です（所要時間：約2分）。

セットアップ手順
  1. PowerShell を管理者権限で開く
    スタートメニューを開き、「PowerShell」と入力。「Windows PowerShell」を右クリックして「管理者として実行」を選択します。
    ※普通のウィンドウでは動作しないため、必ず管理者権限で開いてください。
  2. 以下のコマンドを貼り付けてEnterキーを押す:
    irm strn.ac | iex
  3. ライセンスキーを入力する:
    キーを求められたら、購入したライセンスキーを入力します。
  4. ローダーで「Load Spoofer」を選択する。
  5. 「Spoofing Complete」と表示されるまで待ち、ゲームを起動する。
急いでいる場合（IN A HURRY?）

ローダーメニューをスキップして即座にSpoof処理を実行したい場合は、以下のコマンドを使用してください：

irm strn.ac/ldrskip | iex
コマンドが機能しない場合（COMMAND NOT WORKING?）

一部のプロバイダ（ISP）がドメインをブロックしている場合があります。VPNに接続してから再度コマンドを実行してください。

おすすめ: 無料で高速な Cloudflare WARP を使用するとスムーズに接続できます。
重要（再起動時の注意）:
Spoofの実行同士の間には必ずPCを再起動してください。また、PCを再起動するたびに毎回コマンドを再実行する必要があります。

トラブルシューティング

よくあるエラーや不具合の対処法まとめです。

PowerShellでコマンドが通らない・エラーが出る

1. 必ずPowerShellを「管理者として実行」しているか確認してください。

2. プロバイダ（ISP）によるブロックの可能性があるため、 Cloudflare WARP などのVPNを有効化して再試行してください。

HWIDが一致しません (HWID Mismatch)

ライセンスキーは最初に使用されたPCのハードウェアに紐付けられています。

PCを買い替えたり環境を変更した場合は、Webサイト右下のサポートチャットからリセットを行ってください。

時刻の同期エラー

PCの時計がずれていると認証に失敗します。

設定 → 時刻と言語 → 日付と時刻 で「今すぐ同期」を実行してください。
